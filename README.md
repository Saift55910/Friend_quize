# Friend Quiz

واجهة اختبار أصحاب عربية/إنجليزية متجاوبة، مع لوحة مالك ونتائج خاصة.

## محتويات المشروع
- `index.html`, `styles.css`, `app.js`: واجهة الموقع.
- `supabase/schema.sql`: جداول قاعدة البيانات وسياسات الوصول ودوال التصحيح الآمن.

## التفعيل
1. أنشئ مشروعاً مجانياً في Supabase.
2. افتح SQL Editor وشغّل محتوى `supabase/schema.sql` بالكامل.
3. من Project Settings ثم API انسخ Project URL و anon/public key.
4. ضع القيمتين في أول ملف `app.js`. لا تستخدم `service_role` نهائياً في كود المتصفح.
5. ارفع الملفات إلى مستودع GitHub.
6. من Settings ثم Pages اختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.
7. افتح رابط GitHub Pages وأنشئ حساب المالك، ثم أنشئ الاختبار.

الإجابات الصحيحة لا تُرسل للزائر؛ التصحيح يتم داخل قاعدة البيانات. لا يمكن عرض النتائج إلا لحساب مالك الاختبار.
